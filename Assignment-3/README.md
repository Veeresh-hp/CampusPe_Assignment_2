# 💬 Modern AI Chat UI (Assignment 3)

Hey there! Welcome to my frontend UI assignment. 

This project is a fully responsive, modern chat interface built entirely with **HTML5, CSS3, JavaScript, jQuery, and Bootstrap 5**. The goal was to recreate the sleek, intuitive experience of platforms like ChatGPT and Claude—all without relying on a backend.

## ✨ What's Inside?

I've packed this UI with some really cool features to make it feel like a real AI platform:
- **ChatGPT-Style Layout**: A clean, centered chat interface with floating inputs and a responsive sliding sidebar.
- **Claude-Inspired Animations**: Messages don't just pop in; they slide up seamlessly, and the AI's "typing" effect streams word-by-word with a smooth fade-in effect to mimic authentic generation.
- **Model Selector**: You can switch between different simulated AI models (like ChatGPT, Google Gemini, Ollama, Groq, Hugging Face, and Cohere) directly from the top header.
- **Working File Attachments**: Try clicking the paperclip icon! It lets you pick real files from your computer and displays them as preview chips right above your message before sending.
- **Dark Mode Enabled**: Toggle the switch in the sidebar to see the entire UI seamlessly transition into a beautiful dark theme using dynamic CSS variables.
- **Export Chat**: You can instantly download your conversation history as a neatly formatted text file.

## 🚀 How to Run It
It couldn't be simpler! Since this project is entirely frontend-driven:
1. Just open `index.html` in your favorite modern browser (Chrome, Edge, Firefox, Safari).
2. Type a message, add an attachment, or toggle a few settings and see the magic happen!

## 🛠️ The Tech Stack
- **HTML5**: Semantic structure ensuring solid layout mapping and accessibility.
- **CSS3 / Bootstrap 5**: For a fluid, responsive layout that looks fantastic on both mobile phones and widescreen monitors.
- **JavaScript / jQuery**: Handling all the logic—from auto-resizing text areas to simulating network delays and rendering chat bubbles.
- **FontAwesome & Google Fonts**: Using 'Inter' for that premium, modern typographic feel, alongside crisp vector icons.
